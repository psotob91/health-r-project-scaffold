Minimal Server Transfer Guide

What Gets Copied

Copy only project-mirror/server_payload/ to the offline code server.

What Never Gets Copied

  • Agent files such as AGENTS.md, MEMORY.md, and docs/agent_context/.
  • Real raw data.
  • Private metadata.
  • Uploaded planning evidence unless explicitly approved in a later project-specific plan.

Protected Server Root

Real raw data and private metadata should be placed manually in protected storage after human validation.
