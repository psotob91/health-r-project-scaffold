# Minimal Empty Project Example

This folder is intentionally empty except for this README. It demonstrates the starting point for using `health-r-project-scaffold` in a new project.

Suggested prompt:

```text
Use the health-r-project-scaffold skill to initialize this empty folder as a reduced simulated R health research project.
```

Expected decisions:

- structure: reduced or extended;
- environment: online with agent, offline no mirror, or offline with online mirror;
- storage: single protected root or code/data split;
- data status: simulated, real, or unknown;
- package policy: online installs allowed, package requests only, or offline existing binaries only.

No raw data, private metadata, package inventory, or local machine paths are included in this example.
